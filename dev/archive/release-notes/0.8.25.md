# Release notes — 0.8.25

**Released 2026-09-12.** FathomDB 0.8.25 is published to crates.io, PyPI, and
npm under the annotated `v0.8.25` tag. It remains a pre-1.0 beta release.

The on-disk schema advances from 26 to **33**. Migration runs during
`Engine.open`; review [compatibility](../compatibility/index.md) before opening
an existing database with a newer engine.

## Highlights

- Versioned canonical and derived provenance with immutable revision IDs,
  source locators, and canonical hashes.
- Queryable source dependencies and bounded reciprocal lookup.
- Atomic caller-decided actuation with idempotent terminal receipts.
- Dependency-aware lifecycle and erasure closure with keyed closure status.
- Eligibility-before-ranking and Engine-authenticated frozen read contexts.
- Durable projection-generation identity and receipt-keyed mutation readiness.
- Frozen canonical pagination and current or frozen operational-state reads.
- Opt-in compact source evidence and exact evidence resolution.
- Bounded dependency tracing and constrained graph expansion with deterministic
  work limits and compact explanations.
- Process-start SQLite performance or diagnostics mode selection, plus bounded
  prepared-statement reuse.
- CUDA packaging diagnostics that separate driver availability from the
  artifacts' host/runtime contract.

## SDK additions

Python and TypeScript expose equivalent idiomatic spellings for the new
governed surface. See the [Python API](../reference/python-api.md),
[TypeScript API](../reference/typescript-api.md), and
[errors](../reference/errors.md). Rust consumers use the `fathomdb` facade and
its generated docs on `docs.rs`.

The operator CLI adds the bounded, read-only
`fathomdb doctor data-plane-integrity` diagnostic; see the
[CLI reference](../reference/cli.md#data-plane-integrity).

## Compatibility notes

- Generic published Python and npm artifacts support Linux x86_64/glibc and
  Linux AArch64/glibc. See [compatibility](../compatibility/index.md) for exact
  glibc and CUDA-host boundaries.
- The separately hosted classic Jetson/Tegra wheel remains the exact
  `0.8.24+tegra` interim artifact; it is not replaced by the generic 0.8.25
  package.
- Existing 0.8.25 performance evidence is release evidence, not a universal
  latency SLA. Measure the intended corpus and hardware.

For the exhaustive change list, including removals and fixes, see the
[repository changelog](https://github.com/fathomadb/fathomdb/blob/main/CHANGELOG.md#0825--2026-09-12).
