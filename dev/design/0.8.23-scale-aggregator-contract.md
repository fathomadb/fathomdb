# 0.8.23 scale artifact aggregator contract

This is the executable-contract companion to
`0.8.23-scale-characterization-protocol.md`. It authorizes neither a matrix
run nor a scale conclusion. An aggregator reads retained matrix evidence; it
does not infer, repair, regenerate, or substitute it.

## Input inventory and validation matrix

Every field below is mandatory for `CHARACTERIZED`. Missing planned input is
`MISSING_PREREQUISITE`; present but malformed, contradictory, dirty, corrupt,
or mismatched input is `ENVIRONMENT_INVALID`.

| Group | Required fields/evidence | Validation |
| --- | --- | --- |
| Candidate | full SHA, branch/ref, commit timestamp, clean `git status --porcelain` assertion | SHA resolves; status is empty; any dirty or unavailable fact is invalid. |
| Matching dependency | complete 0.8.22 release-state candidate SHA; Slice 5 SHA/status/evidence; its locked rusqlite, sqlite-vec, and libsqlite3-sys stack | Slice 5 must be LANDED and dependency versions must equal the measured Cargo.lock. Missing closure is prerequisite; a different stack is invalid. |
| Lock/build | Cargo.lock blob and SHA-256; cargo metadata locked digest; schema version/source blob; rustc -Vv; cargo -V; target; release profile; features; complete command; built-process SQLite version | Every digest/blob/version must be nonempty and mutually match the candidate. A shell/tool version is not a substitute for built-process SQLite. |
| Fixture | fixture ID, both seeds, source identity, 384 dimension, 1,000 queries, all three rows, perf_gates blob, canonical descriptor SHA-256 | Exact literal match to the protocol; any difference is invalid, never a new implicit fixture. |
| Host | collect-host-spec JSON, total/available RAM, database filesystem/free bytes, CPU governor/frequency policy, GPU query or explicit unavailable | Required fields must be captured. Explicit unavailable is allowed only where protocol permits; invented zero/unknown is invalid. |
| Isolation | timestamp, load/process evidence, affinity/governor/power/container/VM evidence, explicit no-concurrent-benchmark assertion | Every item must be captured and the assertion affirmative; absence is prerequisite, contamination is invalid. |
| Raw files | exactly 30 named logs and 30 sidecars: rows × treatment × repetitions 1..5 | No extras, duplicate names, missing files, or unreadable files. Each sidecar must verify the raw bytes. |
| Records | exactly one `AC013_TREATMENT_RECORD` per log | Record treatment/rows/repetition must match filename; required metric keys must occur exactly once; unknown record lines/extra records are invalid. |

## Per-repetition schema

Each retained repetition contains: `rows`, `treatment`, `repetition`, raw-log
path/SHA-256, command/exit status, seed/write duration, embedding duration or
the explicitly documented non-observable marker, projection-drain duration,
accepted writes, actual vector rows after drain, drain outcome, result counts,
all query samples, and query errors/timeouts/skips/invariant failures.

`accepted_writes == rows`, actual vector rows equal accepted writes, drain is
successful, exit status is zero, and all error/failure counters are zero are
integrity checks, not defaults. A missing or nonzero value invalidates the
matrix. The aggregator may preserve an incomplete repetition, but may not use
it to satisfy a cell.

`process_cold` has exactly one retained sample and one result count. `warm`
has exactly 1,000 retained samples and 1,000 result counts (or a declared
lossless reproducible histogram plus cardinality). Any other cardinality is
invalid. The treatments are never pooled.

## Outputs and statistics

The artifact preserves every valid/partial repetition under its own cell:
`(10k|100k|1M) × (process_cold|warm)`. For each complete repetition it computes
min, max, mean, p50, p95, and p99 only where defined; cold explicitly omits
undefined within-repetition percentiles rather than inventing them. For each
complete five-repetition cell it reports the repetition-level percentile values
and their median/minimum/maximum. It never pools 5,000 warm samples or five
cold values into a cell percentile.

## Status taxonomy

- `DEFERRED`: no timing was attempted; matrix is empty and summary is null.
- `MISSING_PREREQUISITE`: a required closure, capture facility, host fact, or
  raw input is absent. Preserve partial raw evidence; summary is null.
- `ENVIRONMENT_INVALID`: any dirty/mismatched candidate, malformed record,
  digest failure, extra file/record, failed drain/vector invariant, command
  failure, timeout, contamination, or contradictory provenance. Summary is
  null.
- `INSUFFICIENT_SAMPLES`: all required provenance and retained evidence are
  valid, but one or more cells have fewer than five complete repetitions (or
  wrong treatment sample sufficiency). Summary is null.
- `CHARACTERIZED`: all eight input groups validate, exactly six cells exist,
  each has exactly five complete repetitions, cold has five first-query
  observations, warm has 5×1,000 retained observations, raw digests remain
  verifiable, and only non-pooled summaries are emitted.

Partial, malformed, dirty, corrupt, or mismatched evidence is never
`CHARACTERIZED`, never a threshold pass, and never a supported-scale claim.
