# Slice 20 — CUDA package rehearsal

## Scope

After Slice 10 closes, Slice 20 builds the actual Linux x86_64 Python wheel,
thin npm main tarball, and Linux x64 N-API platform tarball with `embed-cuda`.
All other package lanes remain CPU-only. It retains a non-publishing rehearsal
bundle; it does not create a tag, upload a registry artifact, promote a
dist-tag, or create a release.

## Requirements

**R20-1 — trusted input.** Rehearsal accepts only the exact candidate SHA with
a verified Slice 10 route receipt and preflight witness.

**R20-2 — final-package bytes.** The three Linux x64 consumer artifacts are
constructed with `embed-cuda`, without `rerank-cuda`, and retain the publisher's
existing artifact names and package topology.

**R20-3 — rehearsal manifest.** A strict canonical
`cuda-package-rehearsal/v1` manifest binds candidate SHA, preflight witness
digest, build-input identity, package filenames/SHA-256s, and smoke evidence
digests. It rejects unknown fields, duplicate names, missing files, symlinks,
noncanonical bytes, and altered artifacts.

**R20-4 — installed-artifact smokes.** Python and npm consumers install only
the retained rehearsal bytes. Driverless CPU-default smokes use network-isolated
containers with no GPU nodes and an `env -i` allowlist; they complete
open/embed/write/search/close/exit.

**R20-5 — GPU engagement.** Network-isolated GPU container smokes retain package
digest, selected GPU UUID, host index, device name/driver, requested in-process
ordinal, smoke PID, matching `nvidia-smi` row, and process result. Missing UUID/
PID/device correlation or CPU fallback fails.

**R20-6 — graph and publication boundary.** The read-only CUDA package job
depends on Slice 10 route/witness verification and becomes a required aggregate
predecessor. It cannot publish, tag, use registry credentials, or alter a
dist-tag.

## Acceptance criteria

- RED→GREEN mutations reject CPU-feature substitution, CUDA reranker inclusion,
  duplicate Linux-x64 producers, renamed publisher artifacts, and a missing
  aggregate dependency.
- Manifest tests reject cross-candidate preflight, byte substitution, incomplete
  smoke evidence, noncanonical JSON, and symlinked inputs.
- Smoke tests reject source imports, host-only npm GPU execution, network/GPU
  visibility in CPU containers, and GPU evidence without UUID/PID correlation.
- One authorized dry-run independently reviews the complete rehearsal bundle;
  static tests do not substitute for it.
