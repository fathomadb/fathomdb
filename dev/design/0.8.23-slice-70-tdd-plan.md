# Slice 70 — offline TDD plan

## Implementation boundary

Create a feature-gated `fathomdb-tc5-benchmark` workspace package plus the
narrow `fathomdb-engine` benchmark module. Before that private work resumes,
Slice 70 adds the reviewed public dual-runtime policy, OpenReport/binding
propagation, `doctor gpu`, and Linux x86_64 CLI artifact/rehearsal contract.
The existing global vector-stage test toggle and hybrid `TOP_K_BIT_CANDIDATES`
remain ordinary-search behavior and are not reused.

## Committed RED-to-GREEN order

1. Slice 10 witness v2 migration: RED deterministic fixtures for the exact
   unavailable and visible-incompatible forced `cuda:0` records, their retained
   stdout/stderr filename/hash/root-digest bindings, v1 refusal,
   cache-manifest substitution, CPU-effective mutation, and the read-only HF
   seed plus fresh writable XDG product-cache topology; then Green the
   schema/verifier. This is evidence-contract work only, not a runner dispatch.
2. Deterministic Linux CLI archive: RED static and verifier fixtures for
   `fathomdb-cli` `embed-cuda` forwarding, the exact target/filename/layout,
   archive digest, POSIX PAX `atime`/`ctime` deletion, fixed absolute extracted
   leaf argv, extraction permissions, and the four diagnostic-only CLI doctor
   evidence records; then Green the archive/sealer/verifier contract. Python
   and N-API—not CLI—retain the installed model-operation proof.
3. Production device resolution: RED injected inventory/probe tests for empty
   visibility, one visible UUID with incompatible initialization, one selected
   UUID, forced ordinal mapping, and driver-query failure; then Green the
   CUDA-driver enumeration, UUID inventory/report propagation, and minimal
   mapped-device probe. Deterministic fixture providers cover unavailable and
   visible-incompatible records; real trusted-runner GPU evidence is observed,
   not manufactured by those fixtures.
4. Strict spec/manifest parsing and invocation: exactly `--spec` and `--result`,
   no benchmark-control environment variables, unknown and duplicate fields,
   range/pin/digest failures before open and with no result file, canonical
   length-prefixed SHA-256 bytes, and `proptest` codec round trips.
5. Injected benchmark device policy: no visible CUDA→CPU; one pinned UUID→logical
   `cuda:0`; ambiguous, failed, non-CUDA, or attestation drift→typed failure;
   cache-only asset-unavailable before open with no downloader path.
6. Safe result/output/status contract: identities/timings/cardinality/result
   digests, no raw content/paths/IDs/predictions, malformed-input no-output,
   typed non-measurement device/asset outcome, create-new nonsymlink output,
   and race-safe non-replacing finalization with failure injection.
7. Real SQLite deterministic fixture: request-scoped `ReaderRequest::VectorStage`,
   runner K/top-k propagation, immutable scope/count/selection digest applied
   to candidate/rerank/truth in one deferred snapshot, deterministic
   distance-plus-row-key ties, candidate order distinct from exact ground truth,
   and drift failure.
8. Route observer and timing attribution: a positive
   VectorStage/Candidate/ExactRerank/GroundTruth trace and exact absence of
   Search, FTS compile/query, fusion, graph, and CE. Assert candidate and rerank
   are separately timed CPU SQLite stages and ground-truth timing is separate or
   explicitly excluded.
9. Required-feature binary boundary: strict two-path CLI, no algorithm/device
   environment override, ordinary-build compile failure, benchmark build success,
   and Rust interface update.

No workflow, release helper, or verifier implementation belongs to this
design-only step. Their later RED→GREEN implementation follows the accepted v2
contract and remains candidate-only with no publication.

## Deferred external evidence

Only after Slice 20 package/rehearsal evidence: installed CUDA binary startup,
real CUDA UUID/PCI/name/driver attestation, selected-device engagement, and the
safe deterministic GPU smoke. A real TC-5 GPU run remains contract-invalid until
the external TC-5 execution contract is amended; no characterization is implied.
