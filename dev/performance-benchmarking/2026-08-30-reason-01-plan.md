# REASON-01 treatment eligibility plan

## Outcome

Determine whether an explicit caller-selected FathomDB relationship profile is
eligible for the native HippoRAG-2 comparison. This plan does not change A0,
start the native comparison, or authorize paid answer scoring.

The candidate is `protected_multiquery_v1`. Preserved development evidence
shows that the later deep-compact union added two correct answers over protected
multi-query but lost thirteen grounded answers. Deep compact is therefore a
rejected development offshoot, not the implementation candidate.

## Plan

1. Freeze the [requirements and acceptance criteria](2026-08-30-reason-01-requirements.md).
2. Write the [caller-side design](2026-08-30-reason-01-design.md) and obtain an
   independent read-only subagent design review.
3. Resolve every blocking design finding and preserve the
   [review disposition](2026-08-30-reason-01-design-review.md).
4. Add focused tests first. Use an importable skeleton and record behavioral
   RED assertions for every contract family before implementing behavior.
5. Implement the registry, explicit relationship selection, bounded query
   expansion, protected merge, and safe execution trace; make the focused tests
   GREEN.
6. Run the 282-question selection-equivalence check against the pinned
   development artifact. This is implementation evidence, not acceptance data.
7. Freeze and preflight all 109 untouched LongMemEval-S multi-session cases by
   excluding the 24 cases used in the prior directional run. Preflight is
   zero-spend and writes no model outputs.
8. Run repository verification and update PROGRAM and the status board with the
   implementation and preflight result.
9. Return with the frozen question count, models, estimated spend, and execution
   request. Run held-out answer scoring only after separate authorization.

## Stop

Stop on design-review rejection, inability to reproduce the accepted selection
artifact, any overlap with prior answer-scored inputs, incomplete GPU/reranker
attestation, or a failed repository gate. Do not tune from held-out outcomes.
