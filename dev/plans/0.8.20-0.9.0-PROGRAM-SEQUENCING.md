## Dependency and safety rules

- GPU packaging is Linux x86_64 only until every additional platform has an
  independent reproducible build and hardware smoke.
- CPU remains the default library runtime; CUDA is explicit opt-in and must
  not make a driverless CPU installation unusable.
- The public-repository GPU runner must remain in a workflow-restricted
  organization or enterprise runner group. Labels alone are not authorization.
- A supported-live-embedder reproduction of the Memex scheduler reports, or a
  reproducible abnormal parent-process exit, is a release blocker.
- No-embedder body-bearing graph work receives a typed SDK outcome and readiness
  report; a client may not need to infer configuration from retry exhaustion.
- Embedder availability for graph-edge projection is independent of whether a
  consumer includes vector candidates in its own retrieval/ranking policy.
- Publishing always requires a distinct explicit HITL decision, even after the
  implementation and release rehearsal are complete.
