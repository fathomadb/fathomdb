# FathomDB 0.8.28 draft scope

## Authority

This file preserves bounded advanced-retrieval contracts deferred by the
approved 0.8.25 scope adjustment. It does not authorize implementation or
promotion. The future release must revalidate the consumer value and measured
basis after the narrower data-plane contracts ship.

## Candidate scope

| ID | Candidate work | Required first proof |
| --- | --- | --- |
| D28-01 | Manual named-profile configuration and qualification contract. | At least one non-A0 treatment has a reviewed, reproducible use case; omitted profile remains accepted A0. |
| D28-02 | Specialized time-scoped and changed-fact retrieval profile. | Source-derived external validity evidence shows improvement beyond Slice 35 filtering without truth inference or answer regression. |
| D28-03 | Rich constrained-graph continuation and replayable path evidence. | A consumer needs paths larger than the deterministic one-page Slice 60 result and can state bounded continuation semantics. |
| D28-04 | Expanded deterministic exclusion tracing. | A concrete debugging or compliance decision cannot be answered by the compact Slice 55 inclusion/degradation explanation. |

## Constraints

- Callers select profiles explicitly; automatic routing is not in this scope.
- No treatment changes the default without a separately authorized successor
  decision backed by held-out quality, lifecycle, and efficiency evidence.
- Temporal retrieval returns eligible evidence; it does not decide semantic
  contradiction, supersession, or truth.
- Advanced graph evidence must retain source provenance and bounded execution.
