# Slice 4 review method and ownership

Read authority → actual owner/call path → maturity → proposed delta → observable
invariant → receiving slice. `dev/design/README.md` states accepted ADR/interface
precedence; current-owner-authority.json names current owners/witnesses.

Paths reviewed: open/provider/runtime/close; canonical/projection commit to
ordinary/frozen visibility; eligibility to text/fusion/snippets; MCP admission
through SDK/dispatch/shaping; SDK/native fields to degradation/span reporting.
Use targeted source inspection, not design prose as evidence of implementation.

Record stale docs, code/contract conflict, unsettled semantics and intentional
deferral separately. Actual tests and new counterexamples go to5 and owning
feature slices; hardware/time/performance require later execution. No source,
canonical authority, environment or policy is changed by this review.
