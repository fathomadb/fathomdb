and public docs across `docs/`, `README.md`, `src/python/README.md`,
`src/ts/README.md`, and `src/rust/crates/{fathomdb-cli,fathomdb-sdk}/README.md`.

Controlling invariants for all drafts below:

1. **`dev/acceptance.md` is LOCKED.** No new canonical `AC-NNN` numbers or
   threshold edits. Release `0.8.31` binds behavioral proof to `R31-01`–`R31-08`,
   slice-local ACs (`AC31-*`), and named RED→GREEN TDD tests in feature slice plans.
2. **Governed surface pin (`scripts/check-governed-surface-pin.sh`).** Adding
   `read.operational_collections` / `read.operational_collection` (Slice 10) and
   `resolve_evidence_many` (Slice 40) updates `governed-operation-parity.json`
   and `governed-surface-allowlist.json`; updating `scripts/governed-surface-pin.json`
   requires explicit HITL sign-off. The five-name `recovery_denylist` (`recover`,
   `restore`, `repair`, `fix`, `rebuild`) stays invariant (`AC-041`).
3. **Automated public-doc truth (`scripts/check-public-doc-truth.py`).** While
   `release-state-0.8.31.json` has `published: null`, none of the 16 `PUBLIC_DOCS`
   may assert `0.8.31` is already published; `docs/compatibility/index.md` must
   preserve `"no public automatic migration"` for `Engine::open` alongside
   `SCHEMA_VERSION` **38**; `docs/install/typescript.md` must carry
   `npm install --save-exact fathomdb@0.8.31`; and `README.md` workspace counts
   must match `Cargo.toml` (**13** members including `src/inspector`).
4. **Feature slice allocation (`20+`).** Slice 10 (`features/slice-10/prompt.md`)
   is already commissioned for Schema 38+, Option-1 properties/indexes,
   app-declared vector kinds, op-collection readback, and W12 fixes (with
   targeted `$WT` interface updates). All prework CRUD proposals below are
   allocated to feature slices `20+` (`20`, `30`, `40`, `50`, `60`, `70`) so
   downstream slices reconcile Slice 10 outputs into full interface/public-doc
   parity and deliver new `20+` contracts cleanly.
