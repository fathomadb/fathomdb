### 0.2 Inventory environment needs and decisions

For every area below, record current observed state, required 0.8.25 state,
evidence source and timestamp, gap, recommendation, owner, destination slice,
and whether an action is complete, proposed, blocked, or not needed:

1. **Python and virtual environment** — interpreter versions, development and
   test tooling, native extension provenance, `.venv` ownership, and a
   worktree-safe build/test arrangement. The current ignored `.venv/bin` shim
   is planning-only. Do not run `pip install -e` or `maturin develop` from a
   worktree and do not rebind the primary checkout's environment.
2. **Rust** — pinned/stable toolchain, components, targets, native build
   prerequisites, caches, cross-compilation constraints, and the build source
   actually exercised by verification.
3. **Node/npm and TypeScript** — supported runtime/tool versions, lockfile and
   binding build requirements, and cross-SDK verification prerequisites.
4. **Local native runtime** — CPU capacity, CUDA/driver/toolkit availability,
   ptrace, SQLite/FTS5/sqlite-vec/native libraries, disk, memory, and relevant
   environment constraints. CUDA and ptrace are authorized. Read-only probes
   such as `nvidia-smi` are permitted; do not run a benchmark or mutate system
   configuration.
5. **Tegra/L4T** — Jetson/L4T/JetPack package and ABI assumptions, Python and
   Rust/native artifact requirements, available executor evidence, and the
   packaging compatibility inherited from 0.8.24.
6. **Windows** — required CPU/CUDA, Python, Rust, Node, MSVC, SQLite/WAL, runner,
   artifact, and smoke-test capabilities. Separate 0.8.25 needs from work
   already allocated to 0.8.26.
7. **Local evaluation support** — `data`, models/caches, gitignored `.env*`,
   Airlock, credentials-by-name only, network/registry prerequisites, and
   storage. Never print, copy into a tracked path, or otherwise expose a secret.

Prefer repository and local-host evidence. Mark an external fact unknown when
it cannot be verified safely; do not manufacture readiness from inference.
