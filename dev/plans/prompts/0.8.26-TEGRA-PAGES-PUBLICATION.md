# 0.8.26 Tegra Pages publication handoff

You are completing the narrow post-release publication of
`fathomdb==0.8.26+tegra` for a classic Jetson Orin. The goal is to build,
validate, deploy, and post-deployment smoke-test only that Tegra wheel through
the first-party Pages index. Do not move `v0.8.26`; do not publish to PyPI,
npm, crates.io, or GitHub Releases; do not replace generic artifacts.

## Procedure

1. Confirm `gh auth status`, the remote `release/0.8.26` head SHA, and a clean
   checkout. Confirm the candidate SHA equals that remote head.
2. Read `docs/operations/tegra-pages-publication.md` and run:

   ```bash
   scripts/release/publish-tegra-pages.sh \
     --candidate-version 0.8.26 \
     --candidate-sha <exact-remote-head>
   ```

3. The script dispatches the manual `Jetson Tegra CUDA evidence` workflow with
   `publish_to_pages=true`. That workflow installs Maturin 1.14.1, builds the
   host-native CUDA wheel, proves static CUDA-runtime linkage, runs installed
   CPU/auto/forced-CUDA smoke paths, validates the allocation witness, deploys
   the combined Pages site, and runs the public installed-wheel smoke.
4. Retain the workflow URL, exact SHA, wheel SHA-256, and Pages-smoke evidence.

## Troubleshoot and repair

- Treat the workflow log and its retained evidence as the oracle. Do not use
  `LD_PRELOAD`, add a dynamic `libcudart` dependency, hand-upload a wheel, or
  bypass the exact-SHA check.
- For a build/link failure, add or run a failing check in
  `scripts/tests/test_cuda_release_contract.sh`, repair the pinned Candle or
  Tegra wrapper, and prove no unresolved `cuda*` symbols, no dynamic
  CUDA/NVIDIA dependency, and clean installed-wheel import.
- For device smoke failures, verify `nvidia-smi` exposes classic `nvgpu`, the
  offline model cache is present, and the witness is in-process. Repair the
  workflow/wrapper with a focused regression test before rerunning.
- For Pages failures, repair `scripts/release/build-pages-site.sh` or the
  exact-version index contract; rerun the publisher script on a new reviewed
  release-branch SHA. Do not move the tag or publish a generic artifact.
