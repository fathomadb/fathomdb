# 0.8.23 Slice 30 — Memex embedding readiness and graph integration

## Review and decisions

Reviewed `plan-0.8.23.md`, release state, Slice 0–6 records/workplan/HITL
package, Slice 50, and the baseline commit range. The prepared real-engine
fixture is available; no release artifact or hardware evidence is claimed.
Reviewed the two proposed designs, the N23/R23/AC23 Slice-30 allocations,
authoritative interface documents, and the accepted ADR index.

- Approved N23-EMBEDDER-FEEDBACK / R23-EMBEDDER-OUTCOME and
  N23-MEMEX-CONTRACT / R23-MEMEX-CHARACTERIZATION as this slice's bounded
  contract. AC23 labels remain planning labels; `acceptance.md` is locked for
  per-feature IDs.
- No accepted ADR is contradicted, so no successor ADR is required.
- `EmbeddingReadiness` is Rust-owned and pure: `ready`, `processing`,
  `deferred`, or `blocked`, usable-runtime fact, pending count, affected kinds,
  and an optional stable blocked payload.
- `drain` returns `EngineError::EmbedderRequired` immediately for pending work
  in a no-embedder session. Binding code is `FDB_EMBEDDER_REQUIRED`; the
  payload identifies operation, state, remediations, and documentation URL.
- Body-bearing graph edges project as `edge_fact` and require an embedder.
  Body-less structural edges do not. `graph.neighbors` supports known-root
  traversal without an embedder; query-seeded graph expansion remains tied to
  ordinary vector-seeded search. There is no graph-on/vector-off query mode.
- Worker failures and vector-equivalence refusal remain operational outcomes;
  this slice does not reclassify or hide them. No network, LLM, CUDA, or
  ranking-policy behavior was added.

The design review and disposition are in
`dev/design/0.8.23-memex-integration.md`.
