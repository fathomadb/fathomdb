none of the feature candidates has sufficient completed evidence yet. Existing
tests and workflows are useful seams, not completion credit for the proposed
AC23 criteria. Each approved feature slice must turn the applicable row below
into a RED-to-GREEN test plan before implementation.

## Cross-cutting gate conclusion

`scripts/agent-verify.sh` remains the ordinary lint, typecheck, and test gate,
but it cannot establish restricted hardware, installed artifacts, a first-party
Windows repro, or a completed scale characterization. Feature slices must
retain the normal gate while adding the real-environment evidence assigned
above. Tests must use real databases where the product path does; synthetic
credentials are allowed only as non-secret fixtures that are redacted from
output.

The AC23 labels remain drafts. Slice 6 must present this matrix with the
include/postpone scoring package and obtain HITL disposition before any feature
implementation or authoritative requirements/AC CRUD.
