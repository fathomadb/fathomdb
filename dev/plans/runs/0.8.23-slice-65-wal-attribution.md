## Design and TDD handoff

The design of record is
`dev/design/0.8.23-wal-attribution-investigation.md`. It preserves typed,
fail-closed `ErasureIncomplete`, requires each experiment's RED assertion to
be committed or visibly staged before its GREEN instrumentation/coordination
implementation, and makes all remedies conditional on discriminating evidence.
The future implementation must use the installed Python native binding on
Windows CI for Python cases; mocked SQLite or direct-Rust substitutions do not
meet this record.

No product code, test oracle, public contract, retry value, or CI execution
was performed by this design slice. No design-only lint guard was added, so a
prose-only synthetic RED test would not be meaningful.
