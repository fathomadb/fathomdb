**Written 2026-08-19**, after 80.5 and 80.6 landed and the 80.6.5 git
prerequisite went in. Purpose: enumerate every open item, latent defect, and
deferred question this slice surfaced; state what is actually true of each
*right now*; and rule whether it belongs to 80.7.

**Verified, not recalled.** Every "state" cell below was re-checked against the
tree on the date above. Where a claim came from a subagent report it was
independently reproduced before being written here.

**Disposition vocabulary.** `80.7` = in that sub-slice's scope. `80.6.5` =
belongs to the x86_64 lane. `LEDGER` = cross-cutting, outlives Slice 80, filed
in `dev/todos-and-considerations-ledger.jsonl`. `NONE` = closed, or correct as
it stands and needs no action.

fathomdb` can silently replace the Tegra build with the generic one — **on the

A4 and the decision's own justification is unmet. It is load-bearing, not
polish.

**A4 is not A-something-else.** It is distinct from the AC80-25 co-installation
guard, which under the revised naming should never fire. Implementing one and
claiming it covers the other is explicitly forbidden by AC80-27.
