# Release notes — 0.8.26

**Released 2026-09-19.** FathomDB 0.8.26 is published to crates.io, PyPI,
and npm under the annotated `v0.8.26` tag. npm `latest` and `next` both select
0.8.26. It remains a pre-1.0 beta release.

## Highlights

- Frozen reads now carry finalized explanation correlation identities and can
  resolve exact graph-artifact evidence under the authenticated frozen
  authority.
- The V1 actuation contract supports bounded caller-decided derived-edge
  writes with deterministic validation, replay, dependency, erasure, and
  projection behavior.
- `fathomdb doctor data-plane-integrity` provides bounded immutable inspection
  of dependency and serving-projection authority for a quiescent database.
- The maintained architecture, technical designs, and executable Python /
  TypeScript operation-parity oracle were reconciled to the shipped surface.

## Database boundary

0.8.26 uses on-disk schema **34** and intentionally adopts a fresh-database
public-open boundary. A missing or zero-length path bootstraps directly at
schema 34. A non-empty database opens only when its effective committed
`PRAGMA user_version` is exactly 34; public APIs do not automatically upgrade
older databases.

## Published native artifacts

Python wheels and npm native packages passed post-publication smoke tests for:

- Linux x86_64/glibc;
- Linux AArch64/glibc;
- macOS x64;
- macOS arm64; and
- Windows x64.

Linux musl, Windows arm64/ia32, and other targets remain outside the published
native-package matrix. Rust crates continue to compile from source on supported
Rust targets.

## Install

```bash
pip install fathomdb==0.8.26
npm install fathomdb@next
cargo install fathomdb-cli --version '=0.8.26' --locked
```

The npm channel command remains intentional; `next` and `latest` currently
resolve to the same 0.8.26 package.

The canonical release evidence is retained in the
[0.8.26 release status](https://github.com/fathomadb/fathomdb/blob/main/dev/plans/runs/STATUS-0.8.26.md).
