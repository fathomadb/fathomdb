# Release notes — 0.8.27

FathomDB 0.8.27 is a pre-1.0 beta release. The application surface may change
between micro releases. The [changelog](https://github.com/fathomadb/fathomdb/blob/release/0.8.27/CHANGELOG.md)
contains the complete change list and removed-symbol names.

## Rust application SDK

`fathomdb-sdk` provides the Rust peer of the Python and TypeScript SDKs:
44 governed operations through `Engine`, `read`, `graph`, and `admin`, plus
standalone embedding and reranking. Calls return synchronous `Result` values;
option structs share the SDK defaults. One `Error` type exposes the shared
error categories through `ErrorKind`.

The separate `fathomdb` crate remains the lower-level Rust engine facade.
See [Rust installation](../install/rust.md) and the
[Rust SDK reference](../reference/rust-sdk.md).

## Device delivery and diagnostics

Classic Jetson Orin uses the exact `+tegra` Python wheel and matched-version
Node CUDA tarball from first-party Pages. The Node loader requires both a
Tegra family signal and an `nvgpu` device, and checks the package version
before loading it. Generic Linux AArch64 packages remain CPU-only.

Embedding and cross-encoder reranking have separate CPU/CUDA policies.
SQLite vector retrieval, graph traversal, and fusion remain CPU stages. See
the [platform matrix](../compatibility/index.md),
[Python install](../install/python.md#jetson-tegra-cuda), and
[Node digest verification](../install/typescript.md#classic-jetson-orin-with-cuda).

TypeScript subscribers receive bounded native diagnostics and detach during
replacement and close.

## Internal boundaries and compatibility

Engine modules and source references follow the current semantic owners.
Default dev and release builds remove test-only engine fixtures from the
normal dependency surface. Unit tests retain those fixtures; external test
consumers opt into `fathomdb-engine/test-hooks` explicitly.

The on-disk schema remains **34**. A missing or zero-length database is
initialized at that schema; a non-empty database must already have schema 34.
Public open does not automatically upgrade older databases. The SDK operation
surface and the operator CLI remain separate contracts.

## Install

```bash
python -m pip install fathomdb==0.8.27
npm install --save-exact fathomdb@0.8.27
cargo add fathomdb-sdk@=0.8.27
cargo install fathomdb-cli --version '=0.8.27' --locked
```

Choose the command for your language. See the per-language installation
pages for model features, native platform requirements, and verification.
